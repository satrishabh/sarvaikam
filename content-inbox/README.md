# Content inbox

Place lesson drafts in `drafts/<topic-slug>/` and local attachments in `assets/<topic-slug>/`. Both folders are ignored by Git and the Docker build. Create them when you have material to share.

See [the content handoff guide](../docs/content-handoff.md) for the required content, publishing workflow, and storage locations. Files in this inbox are not automatically imported or published.

Use `lesson-template.md` for editorial drafts. Use `topic-pack.example.json` only as the seed shape for reviewed new content.
